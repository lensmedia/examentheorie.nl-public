# Examentheorie

Welcome to the documentation of examentheorie.nl.
This documentation is mainly for affiliates. You'll find api references and explanation about deep linking 
your students directly to an exam/exercise.

* [Api Reference](api-reference/readme.md) -  Generate access codes, add time frames and get the full list of courses.
* [Deep Linking](deep-linking/readme.md) - Create an access token for sending a student directly into an exam by and url (gained from api references).
