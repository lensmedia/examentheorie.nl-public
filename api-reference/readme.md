# Api Reference

This API is meant for affiliates who work with Examentheorie as their platform to let students study for 
their theory exam. Authentication is via HTTP Basic and login credentials are provided by us.

In our API you can do a number of things, check the routes here:

#### Access Codes
- [Generate](v1/access-code-generate.md)
- [Info](v1/access-code-info.md)
- [Time Frames](v1/access-code-time-frame.md)
- [Disable/Enable](v1/access-code-disable-enable.md)
- [Results](v1/access-code-results.md)
- [Sessions](v1/access-code-sessions.md)
